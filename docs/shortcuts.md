# Keyboard shortcuts

This is every binding in Kbullet 2.1.0, twenty in total. If a key is not listed
here, it is not bound.

## Creating entries

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Set the input type to Task `•` |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Set the input type to Event `○` |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Set the input type to Note `—` |
| <kbd>Enter</kbd> | Add the entry in the input field |

Mood `=`, urgent `!` and priority `*` have no shortcut. Choose them from the
**Type** combo box, or from the buttons beneath the columns.

## Working with a selected entry

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Mark done `×` |
| <kbd>Ctrl</kbd>+<kbd>M</kbd> | Migrate `>` to another day, which opens a date picker |

Edit, delete, un-done, delegated `\` and waiting `|` have no shortcuts. Use the
buttons beneath the columns, or right-click the entry.

## Moving around

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>←</kbd> | Previous day |
| <kbd>Ctrl</kbd>+<kbd>→</kbd> | Next day |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Go to today |

The **Calendar** button opens a date picker, and is available by mouse only. It
has no keyboard shortcut.

## Views

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Week view |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Month view |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Search the whole journal |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Unfinished tasks |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Master task list |

Note that <kbd>Ctrl</kbd>+<kbd>S</kbd> is not save. Kbullet saves automatically
on every change, so the shortcut opens the master task list instead.

## Sorting

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Sort every section by entry type |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Sort every section chronologically |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo the last sort |

<kbd>Ctrl</kbd>+<kbd>Z</kbd> undoes sorting rather than typing. A sort is written
to disk immediately, so the undo only works within the current session. Once you
reopen the app, the previous order has gone.

Each column also has its own sort menu, marked with an up-and-down arrow, for
sorting that section alone.

## File

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a journal file whose name is in `YYYY-MM-DD.md` form |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print the current day |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit |

Settings has no shortcut, and is found in the **File** menu.

## Mouse

| Action | Result |
|---|---|
| Drag an entry | Move it within a section, or to another section |
| Right-click an entry | Open a context menu to edit, delete, change type or mark status |
| Click an entry | Select it, which enables the action buttons |
| Double-click the tray icon | Show or hide the window |
| Drag a column divider | Resize the sections |

A single click on the tray icon does nothing. Use a double-click, or the tray
menu.

## Notation

| Symbol | Meaning | Colour |
|:---:|---|---|
| `•` | Task | Blue |
| `○` | Event | Green |
| `—` | Note | Amber |
| `=` | Mood | Pink |
| `!` | Urgent | Bright red |
| `*` | Priority | Gold |
| `×` | Done | Grey, struck through |
| `>` | Migrated | Purple |
| `<` | Scheduled | Red |
| `\` | Delegated | Teal |
| `\|` | Waiting | Violet |
