# Keyboard shortcuts

Every binding in Kbullet 2.1.0. There are 19 in total — if a key isn't listed
here, it isn't bound.

## Creating entries

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Set the input type to Task `•` |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Set the input type to Event `○` |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Set the input type to Note `—` |
| <kbd>Enter</kbd> | Add the entry in the input field |

Mood `=`, urgent `!` and priority `*` have no shortcut — pick them from the
**Type** combo box or the buttons under the columns.

## Working with a selected entry

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Mark done `×` |
| <kbd>Ctrl</kbd>+<kbd>M</kbd> | Migrate `>` to another day (opens a date picker) |

Edit, delete, un-done, delegated `\` and waiting `|` have no shortcuts. Use the
buttons beneath the columns, or right-click the entry.

## Moving around

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>←</kbd> | Previous day |
| <kbd>Ctrl</kbd>+<kbd>→</kbd> | Next day |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Go to today |

The 📅 **Calendar** button opens a date picker; it is mouse-only.

## Views

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Week view |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Month view |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Search the whole journal |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Unfinished tasks |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Master task list |

<kbd>Ctrl</kbd>+<kbd>S</kbd> is **not** save — Kbullet saves automatically on
every change. It opens the master task list.

## Sorting

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Sort every section by entry type |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>G</kbd> | Sort every section chronologically |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo the last sort |

<kbd>Ctrl</kbd>+<kbd>Z</kbd> undoes **sorting**, not typing. A sort is written
to disk immediately, so undo only works within the current session — reopen the
app and the previous order is gone.

Each column also has its own ⇅ menu for sorting that section alone.

## File

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a journal file (the name must be `YYYY-MM-DD.md`) |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print the current day |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit |

**Settings** has no shortcut — it's in the **File** menu.

## Mouse

| Action | Result |
|---|---|
| Drag an entry | Move it within a section, or to another section |
| Right-click an entry | Context menu: edit, delete, change type, mark status |
| Click an entry | Select it, enabling the action buttons |
| Double-click the tray icon | Show or hide the window |
| Drag a column divider | Resize the sections |

A single click on the tray icon does nothing; use double-click, or the tray
menu.
